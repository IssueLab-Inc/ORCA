THE IDENTITY
A custom geometric ORCA wordmark with diagonal cuts, and a matching split-O
symbol. The approved concept has been reconstructed as editable vector paths.
The wordmark O and standalone symbol use the same geometry. An optical micro
symbol uses a slightly wider cut to stay open at favicon sizes.

WHAT IS INCLUDED

svg/wordmarks/
  Ink black, navy, white and currentColor wordmarks. Fully outlined paths.

svg/symbols/
  Matching split-O symbols in the same four variants.

svg/lockups/
  Wordmark with BY ISSUELAB attribution, in black, navy and white.
  Supporting text is outlined, so no font is needed to use the artwork.

png/wordmarks/
  Transparent PNGs: 512, 1024, 2048 and 4096 pixels wide, three colours.

png/symbols/
  Transparent PNGs: 64, 128, 256, 512 and 1024 pixels, three colours.

png/lockups/
  Transparent endorsed lockups: 1024, 2048 and 4096 pixels wide.

icons/
  Rounded app icons: 64, 128, 256, 512 and 1024 px, plus SVG.
  Full-bleed square app icon SVG and 1024 px store PNG.
  Apple touch icon: 180 px. OS platforms add their own corner mask.
  Android Chrome icons: 192 and 512 px, plus maskable versions.
  Adaptive favicon.svg: black on light browser themes, white on dark themes.
  Transparent and navy-tile favicon PNGs: 16, 32, 48, 64 and 256 px.
  favicon.ico: seven embedded sizes, 16-256 px, navy tile with white symbol.
  Safari pinned-tab SVG, 150 px Windows tile and browserconfig.xml.
  site.webmanifest with relative icon URLs.

social/
  Light and dark 1200 x 630 cards, light and dark 1080 x 1080 squares,
  and a 1584 x 396 profile banner. Each is supplied as SVG and PNG.

video/
  Light and dark 1920 x 1080 title cards, plus black and white transparent
  1920 x 1080 corner-logo overlays. Each is supplied as SVG and PNG.

print/
  Six-page PDF of vector print masters, plus wordmark and symbol EPS files
  in ink black and navy. All print artwork uses RGB colour.

tokens/
  CSS variables and JSON palette / sizing tokens.

source/
  master.json: canonical logo geometry, colours and measurements.
  build-assets.cjs: SVG and PNG export script.
  build-print.py: PDF, EPS, ICO, validation and ZIP packaging script.
  export-list.json: list of outputs made by the JavaScript generator.

reference/
  Approved direction-05 concept sheet. This is a visual reference only;
  all production assets are exported from the vector paths, not the image.

manifest.json
  SHA-256, byte sizes and dimensions for the listed deliverables.
validation.json
  Automated export checks. Visual QA is recorded in source/qa-notes.txt.

Colour space: sRGB. PNGs are exported with an embedded sRGB ICC profile.

SIZING AND SPACING
  Keep clear space of at least 25% of the wordmark cap height on every side.
  Transparent logo SVG/PNG canvases include that space already.
  Wordmark minimum artwork width: 128 px. Endorsed lockup: 240 px.
  Standard symbol minimum width: 24 px. Optical micro symbol: 16-20 px.
  Use the optical favicon artwork for very small display sizes.
  Never stretch, rotate or add shadows to the master marks.
  White transparent PNGs look blank when placed on a white background.

WEB INTEGRATION EXAMPLE
Copy the icons folder under /brand/icons/ and adapt these paths as needed:

  <link rel="icon" href="/brand/icons/favicon.svg" type="image/svg+xml">
  <link rel="icon" href="/brand/icons/favicon.ico" sizes="any">
  <link rel="apple-touch-icon" href="/brand/icons/apple-touch-icon.png">
  <link rel="mask-icon" href="/brand/icons/safari-pinned-tab.svg" color="#052640">
  <link rel="manifest" href="/brand/icons/site.webmanifest">
  <meta name="theme-color" content="#052640">
  <meta name="msapplication-config" content="/brand/icons/browserconfig.xml">

Set start_url and scope in the manifest to the actual hosting path. A manifest
does not itself add offline support. CurrentColor SVGs inherit CSS colour only
when placed inline; img elements do not pass page CSS into an external SVG.
Social graphics have no claim about measured results or engineering approval.

PRINT
Use SVG, EPS or PDF masters. They contain actual paths, not embedded PNGs.
Colours are RGB; ask the printer to convert with the output device's ICC profile
if CMYK is required. PDFs are not labelled PDF/X and no bleed is implied.

FONTS
The main wordmark is custom artwork, not a font. SVG attribution and layout
text are outlined. The PDF guide uses standard Helvetica. Supporting text in
future material can use Segoe UI, Arial or a system sans-serif.
No third-party font file is redistributed in this pack.

REBUILD
Use Node.js with sharp and @napi-rs/canvas available, then Python 3.10+ with
reportlab, Pillow and pypdf. Run from the kit root:

  node source/build-assets.cjs
  python source/build-print.py

If the Node packages live elsewhere:

  node source/build-assets.cjs --deps /absolute/path/to/node_modules

Set ORCA_SUPPORT_FONT to a local Segoe UI font path to reproduce the outlined
support text on a non-Windows system. The font is used only during the build.
The existing master.json is preserved on a rebuild. Edit it deliberately to
change identity geometry, then regenerate and visually check the outputs.

The approved library is stored in assets/brand/orca/ for the upcoming redesign.
Application integration and deployment belong to that subsequent change.
